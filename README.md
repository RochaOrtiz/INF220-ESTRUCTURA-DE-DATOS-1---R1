# 📘 Unidad 0 · Estándares y Buenas Prácticas

En esta unidad se estudian las reglas y recomendaciones necesarias para escribir código Python más ordenado, legible y fácil de mantener.

### Temas principales

* Convenciones de nombres.
* PEP 8.
* Formato e indentación.
* Docstrings.
* Type hints.
* Clases abstractas e interfaces.
* Manejo de errores.
* Organización de proyectos.
* Uso de `if __name__ == "__main__"`.

### 📁 Contenido

```text
unidad0/
├── README.md
├── ejemplos/
│   ├── 01_pep8_y_docstrings.py
│   └── 02_interfaces_abc.py
└── ejercicios/
    └── enunciados.md
```

### 🎯 Objetivo

Aplicar buenas prácticas de programación para desarrollar código más claro, organizado y mantenible.

---

# 📗 Unidad 1 · Modelos de Representación de Datos

En esta unidad se estudian diferentes formas de representar y organizar los datos dentro de un programa.

### Temas principales

* Concepto de dato.
* Tipos de Datos Abstractos (ADT).
* Datos estáticos.
* Datos dinámicos.
* Datos simulados.
* Representación de datos en memoria.
* Complejidad básica de algunas operaciones.

### 📁 Contenido

```text
unidad1/
├── README.md
├── ejemplos/
│   ├── 01_datos_abstractos.py
│   ├── 02_array_estatico.py
│   ├── 03_datos_dinamicos.py
│   └── 04_datos_simulados.py
└── ejercicios/
    └── enunciados.md
```

### 🎯 Objetivo

Comprender las diferentes formas de representar los datos y reconocer qué tipo de estructura puede ser más adecuada dependiendo del problema.
